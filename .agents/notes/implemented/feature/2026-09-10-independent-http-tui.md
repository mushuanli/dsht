# Agent Note: Independent HTTP terminal client

Status: implemented

## Problem

Terminal users need to select existing host workspaces and sessions without launching another agent process or coupling the client to Harness workspace packages.

## Decision

This repository owns a Node.js/Ink executable and a reusable HTTP client. The npm package ships compiled JavaScript and declarations; its single `dsht` bin enables `npx dsht` without a source checkout or a TypeScript loader. The published name is `dsht`, short for DeepSeek Harness Terminal, because npm already holds both the `dsh-tui` package name and a `dsh-tui` bin for an unrelated Harness terminal client, so reusing either would collide on a global install; the executable matches the package name, and local authentication, prices, and usage live under `dsht` directories with `DSHT_*` overrides. The package smoke executes a tarball outside the repository before publication. Published metadata records the author, the MIT license, the repository, and public unscoped registry access, and both READMEs state those fields instead of leaving the name and license to the publisher. The packed set adds the README screenshot and the license file, so the relative image resolves on the registry page; the smoke asserts both paths and still rejects any packed file outside the declared set. `/ws` always selects workspaces, `/s` selects sessions in the current workspace, and `/s all` explicitly widens the list. A missing workspace routes `/s` through workspace selection rather than changing `/ws` meaning. The host remains a separately launched service. Workspace listing consumes the first mux baseline; session listing uses the unary endpoint. Host parameter names remain explicit in every request. A reconnect replaces baseline state and never replays a user mutation. Older hosts send `chunks` wrappers around `chunkrow/*` events and omit the process-local assistant baseline. The reader retains packed starting sequences for paging and folds the unfinished logged attempt for live display; committed assistant messages remain the transcript authority. Treating every wrapper as `event` rejects these hosts, while dropping packed rows loses live text and pagination positions.

File completion uses the host’s `fileReferences/list` and preserves path-only `@` prompt text. Reading local bytes or expanding file contents would change Harness semantics and select the wrong filesystem for remote users. The independent adapter maintains the host mention grammar without importing Harness packages. The composer owns its cursor and local kill buffer because the opaque input component cannot support the required control-key edits; Ink decodes terminal keys and Intl.Segmenter supplies grapheme boundaries. Completion is active only at the end of the draft; obsolete lookups are aborted and their late results ignored. Escape dismisses completion before turn cancellation.

The terminal uses Host running-state notifications for interruption instead of inferring activity from streamed text. Ctrl+C cancels the selected turn before permitting idle exit, while explicit quit retains remote work. Tool arguments and results stay in host history; terminal rows expose only a description or command/path/query summary and hide result bodies. Status icons replace tool-only role headings, and summaries clip to terminal display width. Complete call IDs retain operation labels across interleaved results. Status metrics use the full-log control projections, with per-key sequence checks against late follow snapshots; summing only the loaded window would undercount usage. Context pressure remains approximate, and a locally observed run start is labelled rather than presented as a durable timestamp.

Ink 6 reports both terminal DEL and CSI 3~ as delete; the input adapter observes the raw Ink input event to distinguish backward erase from forward delete, including Meta-DEL and Kitty backspace. Typing reuses the wrapped transcript by transcript identity, revision, and terminal width, while status rendering tracks controller updates separately. The revision increments on follow frames and older pages so reuse cannot hide incoming history. Grapheme lookup is lazy and does not expand the full draft into segment arrays for each ordinary character. In the local synthetic 500-message benchmark, 30 keystrokes caused 30 history reads before reuse and zero afterward; median input/render time measured 375.33 ms before and 6.01 ms after (p95 400.03 / 8.55 ms). These measurements exclude network and model time and are not portable CI limits.

History navigation shares the memoized transcript layout and sequence-to-row offsets. SGR mouse packets are consumed separately from composer input; upward scrolling pages at the retained opening cut, and appended output preserves the reading position. Explicit jumps and current-session search load missing pages with cancellation and reject non-advancing pagination. Cross-session search uses the bounded HTTP search endpoint; workspace filtering preserves the global truncation flag because the endpoint has no workspace filter or continuation cursor. Matching record sequences are located through session history after selection, without reading host configuration or persistence files.

Billing uses durable per-attempt usage rather than differences between cumulative telemetry baselines. Full HTTP history scans retain each request model and settlement time, replace repeated samples, count retries, and exclude inherited fork events. Price versions are explicit non-overlapping intervals with local peak schedules; cached charges retain the applied version. The requested DeepSeek model-family fallback maps names containing pro to Pro and other official-provider names to Flash, below exact configured model entries. The origin-scoped local ledger stores usage and prices without conversation content. Missing attribution remains an unpriced count, and scan failures preserve partial totals; the displayed amount is a CNY estimate, not an account invoice.

The conversation header reads the live title projection before the session-list title and ID. Explicit Esc cancellation bypasses cached running-state admission, shares in-flight cancellation requests, and keeps acknowledgement visible through incoming history until an idle notification. Open menus cancel a known running agent as they close; local navigation or cost loads retain cancellation priority.

Startup configuration accepts the URL that `dsh web` prints, which carries the launch token as a `?token=` query parameter. Splitting that parameter before validation lets users paste the printed line as `DSH_URL` unchanged, while any other path or query still fails so the origin stays unambiguous for cookie and cost scoping. `DSH_TOKEN` keeps precedence over the URL parameter, blank values never authenticate, and the token stays memory-only: only the exchanged cookie reaches disk.

## Alternatives considered

Reusing Cordis client services couples installation and startup to Harness composition. Rust improves native distribution but duplicates more protocol and terminal integration work. Python adds a runtime ecosystem that the requested Node.js implementation does not need. A separate Git repository keeps dependency installation and release history independent.

## Consequences

The adapter must track pre-stable host wire changes. The CLI persists origin-scoped cookies through atomic owner-private files, validates cached authentication before reuse, and only refreshes rejected credentials when a startup token is available. Launch tokens remain memory-only. Slash selectors resolve exact identities or names before unique ID prefixes and reject ambiguity. Unknown waterfalls delegate rather than blocking the host. The tests cover local HTTP/WS transport, user selection, command subprocesses, and recorded transcript projection; they do not claim live model-provider coverage. No existing decision record in this independent repository is superseded.
