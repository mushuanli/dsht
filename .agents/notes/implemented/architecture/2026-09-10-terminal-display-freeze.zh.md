# Agent Note: 稳定的终端复制与对话框背景

Status: implemented

## Problem

流式输出和每秒更新的 Working 时钟会干扰终端原生选区。鼠标捕获接管拖动事件，定时关闭面板也会打断阅读。

## Decision

`/copy` 和 Ctrl+S 冻结已渲染画面，禁用输入框及选择器操作，停止显示时钟，恢复终端原生鼠标行为。Esc、Ctrl+S 或 Ctrl+C 退出此模式，不取消代理。冻结的 React 子树保留展示画面，后台数据接收和正常缓存回收继续。窗口调整是明确的重绘例外。

对话框和选择器冻结背景标题、对话及状态子树，保留自身交互。历史回看时状态时钟也暂停。帮助、状态及费用面板改为显式关闭，不再超时消失。鼠标捕获 effect 在禁用及卸载时恢复终端标志。

## Alternatives considered

降低时钟刷新频率仍会干扰选区。暂停传输可能丢失事件并导致控制状态过期。在对话框期间禁用所有更新，会使异步结果和错误也无法展示。

## Consequences

复制模式需要明确退出才能看到新输出。交互式对话框仍可因用户操作、结果或错误重绘；复制模式冻结整个画面。原生选区行为依赖终端。测试覆盖跨时钟和后台事件的画面稳定、继续接收数据、退出恢复、面板持久显示及状态快照暂停。类型检查、构建及终端测试通过。
