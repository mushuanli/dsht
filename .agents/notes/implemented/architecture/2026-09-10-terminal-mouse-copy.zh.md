# Agent Note: 鼠标进入冻结复制模式

Status: implemented

## Problem

普通聊天输出和 Working 时钟在阅读期间重绘。复制模式能够冻结画面，但此前需要快捷键或命令进入。

## Decision

鼠标报告启用时，无修饰键的左键按下进入现有复制模式，冻结整个界面并释放终端鼠标捕获，随后用户拖动选择。松开鼠标不恢复刷新，Esc、Ctrl+S 或 Ctrl+C 才恢复。滚轮与其他鼠标报告维持原有行为。后台接收继续，不中断远程任务。

## Alternatives considered

终端原生 Shift 选择通常绕过应用鼠标报告，无法可靠自动识别。这种情况及已禁用鼠标报告的对话框仍可用 Ctrl+S 显式进入。松开鼠标立即恢复可能在用户完成复制前重绘。

## Consequences

鼠标复制使用先单击、后拖选的两步操作。测试验证时钟与对话冻结、后台继续接收、忽略右键／移动／释放报告，以及恢复时不取消任务。复制模式现有的窗口尺寸变化行为保持不变。
