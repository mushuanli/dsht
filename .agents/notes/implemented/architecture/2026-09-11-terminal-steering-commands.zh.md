# Agent Note: 终端自动转向与服务端命令

Status: implemented

## Problem

终端用户需要追加输入影响当前任务，而无需选择投递模式。待处理输入需要可见且可删除。服务端还提供计划、目标、权限、反馈和归档功能，终端不能将这些操作当作普通模型提示词发送。

## Decision

所选代理运行时，普通输入通过 `session/prompt` 使用 `steer`；空闲时使用 `queue`。服务端负责下一个步骤的接收和消费，终端不维护第二份待处理消息队列。`session/control` 保留待处理项标识、位置及文本预览。输入框显示待处理的用户输入，`/queue` 打开的列表通过显式删除操作调用 `session/updateQueue`。消息已被领取时显示服务端不存在错误，不会重新发送。仅用于上下文注入的项不提供用户删除入口。重连基线替换已观察的待处理列表。

问题和审批优先于队列选择器及其保留按键。队列回调发送前检查当前待确认状态，存在待确认交互时拒绝普通消息提交。回答仍调用事件结果接口。Escape 关闭队列选择器不会取消代理。

`/plan`、`/goal`、`/permission` 和 `/feedback` 与 `/compact` 共用直接命令执行路径，参数、可用性和忙碌限制由服务端插件负责。成功结果可以省略文本，反馈不进入输入回填历史。命令列表显式声明，分页帮助让短屏也能查看后面的条目。网页导出命令仅通知浏览器下载，因此 `/export` 直接读取经过认证的会话归档路由。本地文件以独占方式创建，流式写入，未完成时删除，绝不替换已有目标文件。

## Alternatives considered

本地转向队列会重复服务端持久化待处理项，产生重连和重复发送歧义。等待整轮结束会错过下一个可用步骤。把 slash 命令作为模型提示词会绕过注册的处理器。仅运行网页导出命令却不下载归档，会在没有创建文件时报告成功。

## Consequences

待处理预览和删除需要服务端控制流及队列接口。终端支持删除，但不支持编辑待处理文本。已领取的输入无法撤回。服务端命令结果仍是本地提示，而非终端历史中的持久化命令卡片。带认证的 HTTP／WS fixture 测试覆盖自动投递模式、删除竞争、交互优先级、命令结果、帮助分页、归档字节、独占创建及取消清理；期望输出 fixture 固定输入框内的消息预览。
