# Agent Note: 终端输入历史回填

Status: implemented

## Problem

输入框没有历史回填，重复提示词或 slash 命令需要重新输入。

## Decision

App 持有有界的进程内输入历史：上下箭头和 Ctrl+P/N 回填输入框，不自动提交。向下越过最新记录时恢复未发送草稿；编辑后结束遍历。提问选项、补全菜单和空输入的导航列表保留箭头操作，导航列表可用 Ctrl+P/N 回填。模态面板禁用回填。

打开或恢复会话时，从已加载的 User 消息初始化回填，排除 Context 内容并将换行转换为空格以适应单行输入框。切换会话释放旧缓存，流式刷新和箭头操作不重复初始化。

历史最多保留 200 条、约 256 KiB 的 UTF-16 文本，合并连续重复内容并跳过超大输入。提交的提示词和命令包括失败尝试，等待交互时的回答不记录。退出进程后丢弃缓存，重新打开时从已加载会话重建，不额外请求历史页或写入磁盘。

## Alternatives considered

拉取全部旧提示词会增加分页和内存保留开销，因此只使用已加载消息初始化。持久化命令历史需要单独的存储与隐私策略。本次进程内回填不需要这两项能力。

## Consequences

用户可以编辑并重新提交旧输入，同时保留未完成草稿。内存占用受限，不随对话长度增长；加载窗口之外的提示词和上次启动的命令无法回填。单元测试覆盖遍历与淘汰，输入框渲染测试覆盖键盘回填、草稿恢复、编辑以及不自动提交。
