# Agent Note: 终端对话框上方的对话上下文

Status: implemented

## Problem

问题、审批或选择器打开时隐藏对话历史，会移除做决定所需的信息。输入区域变高后，冻结的视口也可能保留错误的行数。

## Decision

对话框出现时，所选对话继续挂载在输入框上方。历史可见行数取决于实际测量的高度；冻结渲染标识包含视口高度，让对话框布局变化后仍显示合适的最近上下文。对话框打开时移除历史区域额外的上下边距，并从可见尾部排除末尾分隔空行。

对话框保持打开时，鼠标滚轮及 PgUp／PgDn 滚动对话历史。方向键、数字键和 Enter 继续负责选项与确认。帮助面板的 PgUp／PgDn 用于自身翻页。对话框中的鼠标单击不启用复制模式；Ctrl+S 显式冻结整个画面并释放鼠标捕获。背景自动更新保持暂停，直到对话框关闭或用户主动滚动、调整视口大小。

审批对话框提供编号的允许一次、拒绝和停止轮次操作。数字键和方向键改变选择，Enter 确认。新事件 ID 初始没有选中项，避免上一交互的连续回车批准下一请求。已有草稿、复制模式、离线状态及操作忙碌时禁用审批快捷键，命令仍可使用。这与提问的两键交互保持一致，不引入单键授权或按钮鼠标捕获。界面测试覆盖新请求直接回车、数字批准、方向键拒绝、停止、草稿输入及选项显示文本。

## Alternatives considered

卸载历史能确保选项空间，但会移除决策上下文。冻结渲染标识缺少高度，可能让调整大小后的视口只剩空白或裁剪行。将滚轮交给选项列表，会在用户想阅读上下文时改变答案位置。

## Consequences

输入区域保留现有选项分页及按键归属。终端剩余高度限制可见历史数量。界面测试覆盖问题、审批和模型对话框中的最近上下文、20 行窗口调整、滚轮和键盘滚动时选项不变，以及滚动后的正常确认；复制模式及背景冻结回归仍有覆盖。
