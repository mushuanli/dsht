# Agent Note: 按用户消息分组助手标题

Status: implemented

## Problem

每条助手消息都显示标题，思考、工具调用和后续正文之间重复出现相同角色标签。

## Decision

终端布局在每条 User 消息之后只显示一次助手标题。Context 和纯工具行保留分组，不占用第一段正文的标题位置。已提交内容显示过标题时，流式输出省略标题。当前加载的历史片段自行建立可见分组，不额外请求更早记录。

每个布局片段记录标题可见性以及当前分组是否已显示助手标题。行缓存和高度缓存包含标题可见性。追加消息继承前一片段状态；替换消息或前插历史页时重建受影响的后缀。存储消息和消息序号定位独立于视觉分组。

## Alternatives considered

修改存储中的助手消息会使内容依赖当前加载的相邻记录。每次流式刷新扫描完整对话会增加与变化内容无关的工作。

## Consequences

重复角色标签消失，工具状态、思考链接和正文仍然保留。继续使用有界行缓存和可视区域渲染。回归测试覆盖用户分组边界、工具、Context、流式输出、前插历史以及可见窗口替换。
