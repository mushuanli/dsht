# Agent Note: 账本只按价目表声明的名字定价，且只有金额是终局

Status: implemented

## Problem

模型名过去靠"是否含子串 `pro`"定价：价目表没列出的官方名会静默按 Flash 计费，而恰好含这几个字母的 Flash 名——`deepseek-v4-flash-prod`、`deepseek-proxy-*`——会按 Pro 计费，后者约贵 4.5 倍。宿主报出的名字与官方价目表在大小写、首尾空白、`-expires-on-0910` 后缀、甚至显示路径可能替换成的全角句点上都不一样，因此只做精确匹配几乎什么都定不了价。另外两个决定是"藏起来"而不是"如实报告"宿主记录的内容：没有结算时间的请求取最便宜的空闲价作为下限，这个金额进入历史总计却不进入任何按天区间，于是每日小计加起来不等于总计；官方 DeepSeek 价目表并不定价的缓存写入桶，被按缓存未命中的输入价计费——那是没人公布过的费率。最后，未定价的请求是终局的：后来覆盖了它的表的价目表也无法在不执行 `--reprice` 的情况下为它定价。

在复核同一片区域时又发现三处缺陷，它们在数字上都看不出来：压缩摘要请求——会话中最大的单次请求，因为它要读整个上下文——把自己的 provider、model 与 usage 记在 `compaction/summary` 上，而不是作为 assistant 消息出现，因此忽略该事件的折叠从不给它计费；`loadLedgers` 会删除任何无法解析的文件，这等于把该会话已封存的金额按今天的表静默重算；价目表自身的身份不包含费率信息，因此一个保持了 id 的修正文件可以继续按被取代的费率计费。

## Decision

价格版本声明它覆盖的名字。匹配先按规范化名精确匹配，再按声明的别名匹配（尾部 `*` 为前缀），而价目表未声明的名字保持 `no price version`——猜一个费率与用一个错误费率没有区别。规范化是 NFKC 加上对 NFKC 不折叠的 CJK 句号的显式映射。因此随包 Flash 版本列出了官方声明仍可调用的被取代名字，Pro 版本只列 `deepseek-v4-pro*` 与 `deepseek-v4.1-pro*`：先写下的 `deepseek-pro*` 别名在测试显示它会吞掉 `deepseek-proxy-*` 后被删除，因为前缀别名与它所替代的子串规则一样危险。

只有金额是终局。没有金额的账在每次扫描时重新决定，因此后来覆盖其模型的表、或者本身有错的表，都能在没有修复动作的情况下为它定价；`--reprice` 仍是移动已记录金额的唯一途径。没有结算时间的请求记为 `missing time` 而不是给一个下限金额，这去掉了 estimated 桶并使每日小计之和等于历史总计。官方 DeepSeek 表上的缓存写入桶记为 `unsupported usage`，而不是 dsht 自己发明的费率。每个金额记录匹配规则、引擎版本，以及价格版本自身的摘要，于是审计可以分辨哪些账由旧引擎封存、用的是哪份费率。

`compaction/summary` 按它自己的 provider、model 与 usage 计费，而没有 usage 的摘要——不进行模型调用的模板摘要器——根本不是请求。本构建读不出的账本文件会以 `.unreadable` 之名移到一旁并计数，而不是删除，因为删除会毁掉宿主日志无法再现的那些金额的唯一副本。

## Alternatives considered

对 `pro` 做词边界匹配被否决，因为它只是同一个猜测的缩小版：它仍会把未列出的官方模型按 Flash 定价。只做精确匹配被否决，因为宿主那些带后缀、改了标点的名字都会变成无价——上一版账本正是这样累积到 5,310 笔无价的。保留下限估算被否决，因为高峰档与它的一半空闲档相差一倍，下限在其中一种情况下必然是错的，且无法作为一个可信的小计报告。价目表变化时静默重算在前文已被否决、此处再次否决：未定价的请求现在会自己定价，而已记录的金额仍只在被要求时移动。删除无法读取的账本被否决，因为文件损坏时恰恰是决定最难重现的时候。

## Consequences

`tests/cost/cost.test.ts` 覆盖精确、别名与前缀匹配，包含 CJK 句号与大小写的规范化，含 `pro` 但属于另一个词的名称不会被判为 Pro，未声明的名称不被定价，匹配规则／引擎／费率摘要的记录（同一 id 下改费率会改变摘要），缓存写入被拒，`missing time` 使每日小计等于历史总计，摘要按自身路由计费，未定价请求在表覆盖后自动定价而已定价的等待 `--reprice`，以及区间与重试折叠。`tests/cost/ledger-files.test.ts` 覆盖无法读取的账本以加载器不再读取的名字保留自己的字节。随包表的费率未因本笔记改变；改变的是模型名如何抵达这些费率。
